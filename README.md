# Spotify Global Streaming Data (2024)

## About the Project

This repository contains the **Spotify Global Streaming Data for 2024**, offering a deep dive into music streaming trends across the world. With over 500 entries from various countries, the dataset provides insights into user preferences, top-performing artists, albums, listener behavior, and more.

Key analysis areas include:
- **Global music popularity patterns**: Identifying trends in genre and artist performance worldwide.
- **Listener engagement**: Examining how listeners engage with music across different countries and demographics.
- **Artist performance**: Understanding the success of artists in different regions and the factors contributing to their popularity.
- **Revenue forecasting and content recommendations**: Leveraging streaming data to make predictions on revenue and suggest content improvements.

## Dataset Overview

The dataset provides detailed streaming data for various countries and includes the following columns:

- **Country**: Country where the streaming data is recorded 🌍
- **Artist**: Name of the music artist 🎤
- **Album**: Name of the album released by the artist 💿
- **Genre**: Musical genre of the album or artist 🎶
- **Release Year**: Year in which the album was released 📆
- **Monthly Listeners (Millions)**: Average monthly active listeners in millions 👥
- **Total Streams (Millions)**: Total number of times the artist's content was streamed (in millions) 🔁
- **Total Hours Streamed (Millions)**: Total hours users spent listening to the artist (in millions) ⏱️
- **Avg Stream Duration (Min)**: Average duration of each stream in minutes ⏳
- **Platform Type**: Whether the listener is using a Free or Premium account 💳
- **Streams Last 30 Days (Millions)**: Streams generated in the last 30 days (in millions) 📈
- **Skip Rate (%)**: Percentage of tracks skipped before completion ⛔

## Features of the Analysis

The following insights can be derived from this dataset:
- **Top-performing artists and albums**: Identifying the most popular artists and albums across different countries and regions.
- **Listener demographics and behavior**: Analyzing listener preferences and engagement patterns based on genre, platform type (Free vs. Premium), and average stream duration.
- **Genre-based trends**: Visualizing global trends in genre popularity and how they vary by region.
- **Artist and album recommendations**: Based on listener behavior and streams, creating recommendations for content creators and music platforms.
